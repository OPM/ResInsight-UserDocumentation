### Window Tiling
Tiling of windows can be accessed from the tool bar. The default tiling will organize the windows in a grid pattern. The window management feature is available from the **Windows** menu at the main menu bar.

 ### Window Management

The window management system was updated in release 2022.06.1. ResInsight stores application window visibility and location between sessions.

The window management is available from the **Windows** menu.
